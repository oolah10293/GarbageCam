# GarbageCam roadmap

## v0.1 — prove the stream

- Rear Camera2 source
- Hardware H.264 via MediaCodec
- Local RTSP server
- Adjustable resolution, FPS, bitrate, H.264 profile and keyframe timing
- Foreground service for screen-off operation
- CPU/Wi-Fi wake locks
- RTSP authentication
- ANNKE-shaped presets based on an I51DS reference camera

## v0.2 candidates

- Live preview / aiming screen
- Explicit CBR/VBR selection
- Better runtime codec-capability inspection
- Camera focus/exposure controls
- Optional audio
- Auto-start after boot
- Timestamp overlay

## Later

- Independent main/sub streams
- ONVIF discovery/control
- Multiple camera/lens support where hardware allows it
- NVR-oriented presets for other recorder families
